# Apple Mail MCP

在聊天中控制 macOS 自带的「邮件」App。本地运行，无第三方 Python 依赖，无需保存邮箱密码。

## 功能

| 工具 | 功能 |
| --- | --- |
| `mail_accounts` | 列出已配置的账号 |
| `mail_mailboxes` | 列出指定账号的文件夹路径 |
| `mail_selection` | 读取当前选中的邮件 |
| `mail_search` | 按主题、发件人和未读状态搜索 |
| `mail_unread_counts` | 完整统计未读数量 |
| `mail_mark_all_read` | 批量标记已读并逐文件夹核验 |
| `mail_read` | 按账号、文件夹路径和编号读取正文 |
| `mail_update` | 修改已读状态或旗标 |
| `mail_move` | 在同一账号内移动邮件 |
| `mail_draft` | 创建并保存可见草稿 |
| `mail_send` | 发送已打开的草稿 |

## 环境

- macOS，已在「邮件」App 配置邮箱。
- Python 3.9 或更新版本；可先检查 `/usr/bin/python3 --version`。
- 系统自带 `/usr/bin/osascript`。
- 支持 MCP 标准输入输出连接的客户端。

## 使用本地工具

在源码目录运行：

```sh
codex mcp add apple-mail -- /usr/bin/python3 "$PWD/server.py"
```

其他 MCP 客户端可按自身配置格式指定 Python 为命令、本目录 `server.py` 的绝对路径为参数。若 Python 安装在其他位置，请相应替换命令。

重新加载客户端的 MCP 连接。首次调用时，macOS 可能询问是否允许宿主控制「邮件」。相关权限位于「系统设置 → 隐私与安全性 → 自动化」。

示例请求：

- “总结邮件 App 当前选中的邮件。”
- “列出可用邮箱，再查找其中的未读邮件。”
- “为这封邮件创建回复草稿。”

## 作为个人插件安装

仓库包含 `.codex-plugin/plugin.json` 和本地插件目录清单。在源码目录先运行：

```sh
python3 configure.py
```

这会生成仅用于当前机器的 `.mcp.json`；该文件受 `.gitignore` 排除。移动源码目录后须重新运行。然后使用客户端支持的本地插件目录安装流程，选择 `.agents/plugins/marketplace.json` 中的 `apple-mail`。

本仓库的插件目录是本地源，需要先取得源码并生成配置；它不是可直接远程安装的插件市场。客户端的具体本地目录导入方式可能不同。不要同时启用独立 MCP 连接和插件中的同一服务，否则工具会重复显示。

## 范围与限制

- 搜索默认扫描指定文件夹前 500 封，每页最多 2000 封；不保证按时间排序。`possibly_more` 为真时，用 `next_offset` 作为下一次的 `offset` 继续扫描；邮箱变化时应重新开始。
- 正文默认最多返回 12000 字符，可请求最多 50000 字符。
- 账号名和文件夹路径应通过工具发现，不能假设不同邮箱的本地化名称相同。
- 仅支持同一账号内移动；归档和移到废纸篓需要选择实际目标文件夹。不提供永久删除工具。
- 草稿工具是新建草稿，不会自动构建原邮件的回复线程。
- 发送工具只接受仍在 Mail 中打开的草稿编号；只有在用户明确要求发送时才应调用。该限制依赖客户端遵守工具说明，并非服务端的独立授权机制。
- 原型已进行真实只读验证；修改、移动、草稿和发送尚未完成真实邮件写入验证。

## 隐私

服务本身不联网，不保存邮箱密码，也不把邮件正文写入日志。邮件读取结果会返回调用它的聊天客户端，因此会进入该客户端的上下文，并受客户端的数据处理规则约束。

邮件正文属于不可信外部内容，不能当作操作指令。macOS 自动化权限适用于整个邮件 App，工具名称或只读标记不是系统权限隔离。

请勿提交本机生成的配置、账号列表、邮件样本、截图、运行日志或备份。

## 本地检查

```sh
python3 -m unittest discover -s tests -v
```

这些测试使用模拟数据和模拟进程，不读取真实邮箱，不修改或发送邮件。

独立 MCP 接入可通过 `codex mcp remove apple-mail` 移除；个人插件可在客户端的插件页面卸载。卸载连接不会删除邮件。

## 0.2.0 更新

批量统计与标记已读支持所有账户、指定账户和指定文件夹。省略范围表示所有已配置账户，包括垃圾邮件与废纸篓；提供 `mailbox` 时必须同时提供 `account`。全局和账户范围递归处理子文件夹，指定文件夹只处理该文件夹。

结果包含逐文件夹核验与部分失败信息。Gmail 标签可能重叠，未读统计是文件夹出现次数，未经跨标签去重。核验反映本地 Mail 状态，服务器同步可能延后。搜索移除了逐条结果的重复文件夹定位。

新增功能通过模拟测试；真实 Mail 批量写入尚未验证。更新后重新加载 MCP 连接以获取新增工具。

可选的桥接模拟测试（需要 Node.js，仅开发测试使用）：

```sh
node tests/test_bridge.js
```
